# Pet Shop - Projeto Front-End

Este é um projeto de site para Pet Shop, desenvolvido para fins de estudo e prática de HTML e CSS.

## Estrutura do Projeto
- `index.html`: Página principal do site.
- `style.css`: Estilos e responsividade do site.
- `img/`: Pasta com imagens utilizadas no site.

## Funcionalidades
- Layout moderno e responsivo para desktop, tablet e celular.
- Seções para apresentação de serviços, sobre e contato.
- Botões estilizados e adaptados para diferentes tamanhos de tela.

## Como usar
1. Clone este repositório:
   ```sh
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```
2. Abra a pasta no VS Code ou outro editor de sua preferência.
3. Basta abrir o arquivo `index.html` em seu navegador.

## Imagens
As imagens utilizadas estão na pasta `img/` e são apenas para fins ilustrativos.
